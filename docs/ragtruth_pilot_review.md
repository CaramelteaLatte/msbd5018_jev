# RAGTruth pilot 开发检查与正式协议冻结

决定：保留 pilot 的现有核验提示词、模型、thinking=false 和 LLM 输出上限 32 tokens，不按这 48 条调参或修改人工标签。提示词已要求检查所有事实，外部真实但材料未支持的内容计为 H；拒答本身不计 H。主评分继续包含 implicit_true，另用同一批预测报告排除此类片段的敏感性分析。

正式主指标为 H 类 F1，同分依次比较 accuracy、较少转交；每个 LLM 独立选阈值，训练选择集合上转交最多 20%，confidence 相同者整组处理，包含不转交。按 source_id 做固定五折，完整 validation 最优分数与折外分数分开。固定协议和输入哈希见 [ragtruth_protocol.json](../code/ragtruth_protocol.json)。正式 test 只使用 validation 固定策略；按 source_id 做 10,000 次配对 bootstrap，报告 accuracy 和 H F1 差值。
